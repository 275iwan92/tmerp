- **Document type**: concept card (master data, not a document). **Module/sub-module**: Inventory > Warehouse > Setup (`INV_WH_SETUP` group: `INV_WH_BLD` `v2:wh-buildings`, `INV_WH_ZONE` `v2:wh-zones`, `INV_WH_BIN` `v2:wh-bins`, `INV_REF_WH` `v2:md-warehouse`; FACT `sys_app_menu`, all active).

## Findings (recorded, not fixed)
1. **Count lock claim vs reality**: see card `16_card_count-task.md` finding 1 (`count_lock` is a column of the bin but is read in only a few places).
2. **VIRT building cannot be saved from Buildings**: `BuildingLookup` lists every `wh_warehouse` row but its rule allows only MIX/RM/SFG/FG/WASTE/TRANSIT for `warehouse_type`; the system row `VIRT` has type VIRTUAL, so saving it in that grid would fail validation. FROM CODE (`BuildingLookup.php:93`), not tried on screen.
3. **Bins without an area**: 7 bins (the 5 old buildings) have `zone_id` NULL. The map says "N bins have no storage area yet, so they are not on the map". Bin `WH-SCP-01-R09-C01-S01` is not usable and has an empty `block_reason`, which the Bins screen would now refuse. FACT (query).
4. **Stale block**: bin `A10-PPR-L06-06` is blocked with the note "Floor repair until 15-Oct-2026"; today is 16-Oct-2026 and nothing releases it automatically (Unblock is manual). FACT.
5. **No area uses the rules**: all 16 areas have `mix_rule=ANY`, `count_every_days` NULL and no `max_stack`, so Mixing, scheduled counting and the stack limit are untested on real dummy data. The dummy has a STAGING area (A10-STG) but no WIP area. FACT.
6. **Two screens for one table**: Buildings (v2) and Master Warehouse (v1 grid) both edit `wh_warehouse`; the old grid does not know the size/shape/height columns. FROM CODE (`WarehouseGrid.php`), not opened.
7. **Bin code uniqueness is global** (`m_wh_location_bin_code_unique` on `location_code` alone), while generated codes start with the building code; a second company-wide scheme with the same code in two buildings is impossible. FACT (`show index`).
8. **Zone rules are only partly checked in the database**: `wh_zone.zone_type`, `storage_mode`, `mix_rule`, `pick_order` are varchar, valid values are enforced only in the screen rules (`StorageAreaLookup.php:114-118`). FACT.
