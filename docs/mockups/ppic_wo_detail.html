Why this matters to the scheduler

The engine reads dieline, imposition, BOP, routing and BOM from ProDev when it creates the Work Order.
It only offers machines that fit the sheet size, board weight, colours and process (Product and dieline tab).
Run time = qty in over target per hour, plus setup, so each bar on the Gantt has the real length.
MRP uses the same cascade, so material, booking and the scheduled quantity always agree.
If actual waste runs above the allowance, Monitoring flags it and the learning engine adjusts the assumed value.
