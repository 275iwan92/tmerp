→
2. Imposisibelum ada layout: hitung dari flat Inquiry, jadi DRAF (memori/session, tidak ke DB).
→
3. BOPtemplate tipe Confirmed? ya: kerangka dari template; tidak: aturan umum seperti sekarang.
→
4. BOMbahan Inquiry + bahan template; qty dari lembar cetak BOP.
→
5. Alasanyang belum bisa: tulis sebabnya per baris dan di panel status.

6. Officermengubah atau Save/Confirm; override tidak pernah ditimpa. Tidak ada tulis DB sebelum Save.
