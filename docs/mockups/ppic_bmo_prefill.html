What happens after Send request

P1 on a stopped machine goes straight to a Breakdown Maintenance Order and starts the downtime.
The machine is marked Down. Production Scheduling shows a red Down band on the Gantt.
The operator timer stays paused with the reason Machine problem.
Jobs on Die-Cut 01 are listed under "Needs re-schedule" with the forecast delay; the PPIC officer presses Re-plan.
When maintenance presses Done, the downtime closes, the machine returns to ready and the schedule is re-planned automatically as a new Draft.
Number BMO-yymm-nnnn is given when the head accepts the request.
