# PORTABLE DEMO GUIDE FOR TOP MANAGEMENT
## Offset Packaging ERP Suite — Executive Presentation

Panduan presentasi cepat dan mandiri untuk mendemokan sistem kepada Top Management / C-Level Executives.

### Keunggulan Utama untuk Dipresentasikan:
1. **Kecepatan Input Sales**: Pengisian spesifikasi kemasan kompleks hanya membutuhkan waktu 2-3 menit (dibandingkan formulir manual / Excel 30 menit).
2. **Kalkulasi CAD Otomatis**: Bentangan pisau pon dihitung secara matematis presisi tanpa menunggu tim prepress CAD.
3. **Dukungan Kemasan Multi-Part (Contoh: Dus Sepatu 2-Pc)**:
   - Tunjukkan mode **Side-by-Side (2 Dieline)**: Memperlihatkan pisau badan sepatu dan pisau tutup sepatu terpisah secara berdampingan.
   - Tunjukkan **3D Exploded View**: Geser slider *Elevasi Tutup* untuk memperlihatkan tutup yang mengambang terangkat di atas badan kemasan.
4. **Portabilitas 100% Offline Tanpa Instalasi**:
   - Dapat dijalankan langsung dari USB flashdisk di laptop Windows 10 / 11 mana pun tanpa perlu install Node.js, PHP, atau database lokal.
