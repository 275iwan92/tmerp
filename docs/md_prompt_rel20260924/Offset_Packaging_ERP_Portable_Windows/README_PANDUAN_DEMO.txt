# PANDUAN MENJALANKAN OFFSET PACKAGING ERP (PORTABLE EDITION)
# Khusus Windows 10 & Windows 11 (100% Offline Tanpa Koneksi Internet)
========================================================================================

APAKAH BENTROK DENGAN LARAVEL HERD DI LAPTOP ANDA?
JAWABAN: TIDAK SAMA SEKALI!
- Laravel Herd biasanya mendengarkan port 80, 443, dan 8080.
- Skrip "Buka_Aplikasi_Demo.bat" telah diatur menggunakan Port Khusus: 32145.
- Jadi Herd Anda tetap bisa aktif mengerjakan proyek Laravel Anda seperti biasa tanpa terganggu!

========================================================================================
CARA MENJALANKAN DEMO KE BOS / DIREKSI:
========================================================================================

PILIHAN UTAMA (PALING DIREKOMENDASIKAN):
1. Cukup double-click file:
   👉 "Buka_Aplikasi_Demo.bat"
2. File ini otomatis menyalakan server lokal Windows bawaan pada port 32145 dan langsung
   membuka browser Chrome / Edge ke http://localhost:32145/ secara instan!
3. Seluruh fitur, CAD SVG Dieline, dan 3D Mockup berjalan 100% lancar.

PILIHAN ALTERNATIF (BISA DOUBLE-CLICK FILE HTML):
1. Double-click file:
   👉 "RUN_DEMO_OFFLINE.html"
2. Menggunakan format single-file mandiri.

========================================================================================
FITUR UTAMA YANG SIAP DIDEMOKAN:
========================================================================================
1. Live Dieline Mockup (CAD SVG):
   - Klik preset ukuran (Cube 100, Hampers, Martabak, Skincare, dll) -> pola CAD berubah.
   - Ubah ukuran Length (L), Width (W), Height (H) -> garis potong (merah) & rel creasing (hijau) update dinamis.
   - Tombol "Download SVG" untuk export file pisau pon.

2. Upload Artwork & Live Mapping:
   - Klik tombol upload "Artwork / Design File", pilih gambar JPG atau PNG (foto packaging / logo).
   - Gambar otomatis menempel di kanvas Dieline CAD dan langsung membungkus pola box!

3. Interactive 3D Packaging Preview:
   - Terletak di luar kotak dieline CAD.
   - Dapat di-klik dan di-drag mouse untuk diputar 360 derajat secara bebas.
   - Dilengkapi tombol "Auto-Spin", Zoom In/Out, dan Reset Angle.
   - Artwork yang diupload langsung membungkus muka depan, belakang, dan samping box 3D.

4. Imposisi Mesin Cetak Offset:
   - Klik tombol "Imposition" di navigation bar atas untuk melihat tata letak pisau potong pada lembar kertas plano lengkap dengan gripper dan side margin.

5. Cetak Production Brief (SPK):
   - Klik tombol "Print Note" untuk mencetak atau simpan PDF form briefing produksi resmi lengkap dengan tanda tangan.
