Patokan Data Dummy

Jo, 14 Okt 2026. Mencatat pemahaman yang sudah dijawab "Paham". Versi teks: docs/PATOKAN-DATA-DUMMY.md.

Cerita singkat

1. Tujuan. Setiap data dummy punya dieline, artwork, dan ukuran produk yang jelas (P x L x T, ukuran datar, mm).
2. Sumber. Master Card Jo ada di Excel, lalu dijadikan PDF supaya bisa dibaca. PDF di folder docs/attachments/mastercard/ adalah sumber isi data dummy.
3. Dibuat berlevel, dalam beberapa set. Jumlah set tidak dikunci ("misal 12 set atau entah berapa"). Contoh Jo di tabel di bawah.
4. Level maju membawa jejak lengkap di belakangnya. Set yang sudah masuk CO berarti ada Inquiry, ProDev, dan ProCost untuk set itu juga.

Level dan contoh jumlah set

LevelPosisi set di alurContoh jumlah
1Baru Inquiry saja2 set
2Sudah di ProDev2 set
3Sudah di ProCost2 set
4Sudah masuk CO2 set

Jejak mundur sebuah set di level CO

Inquiry→ProDev→ProCost→CO

Satu set di level CO harus punya keempat tahap di atas (data yang sama: inquiry, produk, part, qty). Set di level 1 hanya punya tahap Inquiry. Tidak boleh ada tahap yang loncat.

Aturan turunan

  • Setiap set, di level mana pun, membawa dieline + artwork + ukuran produk (P x L x T) + ukuran datar (mm) sejak Inquiry.
  • Set dibuat per level, bukan campuran: tiap set berhenti tepat di levelnya.
  • Set level N bisa ditelusuri mundur ke level N-1 ... 1 dengan data konsisten.

Engine (dibuat 14 Okt 2026)

PDF baru di docs/attachments/mastercard/ diproses satu perintah (hanya ddt*):

php artisan dummy:mastercard --env=mockup --levels=inquiry:2,prodev:2,procost:2,co:2

  • Gambar kartu (bentuk / dieline) = berkas di extracted/ dengan nama slug PDF-nya.
  • Produk baru diisi ke level sesuai kuota, urut berkas. Tanpa --levels: semua ke level Inquiry. Opsi: --qty (5000), --due (21 hari).
  • Level N membawa semua level di belakangnya; berhenti di CO Confirmed (baris CPDEL lahir, belum di-Post).
  • Kartu tanpa artwork, ukuran P x L x T, ukuran pisau, atau bahan tidak dibuat, alasannya dilaporkan. Produk yang sudah ada dilewati.

Belum diputuskan Jo (jangan diisi sendiri)

  • Jumlah set total dan jumlah per level.
  • Apakah ada level setelah CO (Post to Production / WO / plan), dan berapa set per level itu.
  • Set mana dari PDF yang masuk level mana.
