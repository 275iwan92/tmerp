Aturan Layar TMERP

Aturan baku per jenis layar: grid, form dokumen, dan seterusnya. Setiap bagian punya teks prompt siap salin untuk sesi Claude, jadi aturan yang sama dipakai di semua layar tanpa diulang dari awal.

Disusun 26 September 2026 dari objek DevLib (x-dl::grid / x-dl::master, devlib.test) dan arahan Johannes Iwan hari ini. Pendamping Pegangan Fase TMERP.

Cara pakai

  • Bagian bertanda Untuk dibaca sudah berlaku di kode, menunggu Anda baca dan koreksi.
  • Bagian bertanda Draf belum dikunci. Masih ada keputusan terbuka.
  • Setelah Anda setuju, tanda berubah jadi Dikunci. Prompt di bagian itu lalu dipakai apa adanya di setiap sesi.
  • Perubahan aturan cukup dilakukan di halaman ini. Sesi Claude berikutnya membaca dari sini.

Grid

Untuk dibaca

Sumber kebenaran = DevLib (devlib.test → Grid, Form & Dokumen). Layar tidak menggambar grid sendiri: pilih satu varian DevLib, isi kolom dan data asli, selesai. Perilaku (cari, sort, filter, kolom, export, paginasi, klik 2x) datang dari komponen x-dl::grid. Kalau ada yang kurang, yang diubah komponen DevLib-nya, bukan layarnya. Grid dibagi tiga keluarga dengan tujuan berbeda: Pre-Data Entry, Reporting, dan Special.

A. Grid for Pre-Data Entry mode="entry"

Pintu menuju form: mencari record untuk dibuka, diubah, atau di-Confirm. Baris lega dan setiap baris diberi kotak kecil (centang di kiri, kotak ikon Aksi di kanan). Grid for Master punya kotak pratinjau di kolom pertama: kotak foto (klik = perbesar); bila record belum punya foto, kotak yang sama berisi inisial nama. Kolom nama di sebelahnya tanpa bulatan avatar.

#Varian DevLibDipakai untuk
1Master (kotak foto + Edit + Aktif/Nonaktif)Customer, Mesin, Bahan, Pegawai
2Single Transaction (worklist)Dokumen tanpa item; tab status + Buka/Confirm
3Master-Detail (baris dibuka = item)Dokumen ber-item: Quotation, CO, DO, PR, PO
4Status Bar (tahapan + progres)Worklist produksi (WO)
5Photos (tabel ↔ kartu)Data dengan foto asli
6Mix ComponentSaklar, rating, tren, tombol di dalam sel
  • ToolbarCari + Kolom + Kerapatan + Export + + New Record (Filters dan Grup muncul bila diisi). Semua bawaan DevLib, tidak ditambah atau dikurangi per layar.
  • Kolom centang di kiriSelalu ada (Shift = pilih rentang). Aksi massal hanya dipasang bila layar memerlukannya.
  • AksiMaster: Edit + Aktif/Nonaktif. Transaksi: Buka selalu, Confirm hanya pada baris yang memenuhi confirm-when per layar (Quotation = DRAFT, PO = SUBMITTED).
  • Klik 2x = buka formForm Edit sama persis dengan form New. Panah di kiri membuka isi baris di tempat (field tambahan atau tabel item), hanya baca.
  • Kotak statistik, tab, baris TotalKotak statistik pastel = filter klik/lepas; tab status untuk worklist; kolom bernilai dijumlah di baris "Total (semua hasil)". Paginasi ala ScriptCase, default 25.

B. Grid for Reporting mode="report"

Untuk membaca data, bukan mengubahnya. Datanya bisa ribuan baris walau sudah difilter, jadi grid dibuat rapat supaya satu layar memuat banyak baris. Fokusnya cari dan filter. Semua varian di keluarga ini (Report List, Group By, Summary, Pivot) tanpa kotak di baris.

#Varian DevLibDipakai untuk
1Report List (rapat + saring per kolom)Laporan daftar: faktur, mutasi stok, riwayat transaksi
2Group By (+ subtotal)Laporan yang dibaca per kelompok
3Summary → Details (drill-down)Ringkasan per supplier/customer, klik 2x = rincian
4PivotLaporan silang (customer × bulan)
  • Tanpa kotak per barisTidak ada kolom centang, kolom Aksi, maupun + New Record; avatar disembunyikan. Baris rapat, huruf lebih kecil, warna selang-seling.
  • Satu tombol Filter → pop-upTidak ada bilah filter atau baris saring di atas tabel. Tombol Filter di toolbar membuka pop-up berisi Pilihan (dropdown seperti Kategori, Sales, Status) dan Per kolom (teks = mengandung; angka boleh >1000, <=5, =12). Berlaku setelah Terapkan (atau Enter); Reset mengosongkan semua. Angka di tombol = jumlah kriteria aktif, dan tiap kriteria tampil sebagai chip yang bisa dilepas. Di samping tombol: "N baris cocok dari M".
  • Kepala tabel tetapTabel bergulir di dalam kotaknya dan judul kolom tetap terlihat. Paginasi 50/100/250/500, default 100. Export = kolom yang tampil.
  • Data ribuanDi tmerp, paginasi dan penyaringan jalan di server (bukan muat semua lalu saring). Relasi lintas database dicari bertahap, bukan whereHas bertingkat. Kriteria besar (periode, dsb.) boleh didahului Form Filter / Kriteria Laporan.

C. Grid Special x-dl::sheet

Grid yang selnya langsung diedit seperti Excel, bukan pintu ke form dan bukan laporan. Dipakai hanya untuk edit massal master kecil berkolom sederhana (harga bahan, satuan, kurs).

#Varian DevLibDipakai untuk

Prompt Grid untuk sesi Claude
Bangun/ubah GRID di TMERP mengikuti "Aturan Layar TMERP" bagian Grid.
Sumber kebenaran = DevLib (devlib.test > Grid, Form & Dokumen), komponen x-dl::grid.
Jangan menggambar grid sendiri dan jangan menambah/mengurangi perilaku per layar;
kalau kurang, ubah komponen DevLib-nya.

1. Tentukan keluarga:
   - PRE-DATA ENTRY (mode="entry"): pintu ke form. Varian: Master, Single Transaction,
     Master-Detail (dokumen ber-item: Quotation/CO/DO/PR/PO), Status Bar, Photos, Mix.
   - REPORTING (mode="report"): baca data ribuan baris. Varian: Report List, Group By,
     Summary -> Details, Pivot.
   - SPECIAL (x-dl::sheet): sel langsung diedit ala Excel, hanya master kecil berkolom sederhana.
2. Tiru demo varian itu apa adanya (devlib/resources/views/demos/grid-*.blade.php);
   ganti hanya kolom dan sumber data asli.
3. Entry: centang kiri, Aksi Master = Edit + Aktif/Nonaktif, Transaksi = Buka + Confirm
   (confirm-when per layar, mis. Quotation ['status' => 'DRAFT']). Klik 2x/Buka/Edit =
   open-url ke form yang sama dengan New. Dokumen ber-item: detail = tabel item.
4. Report: tanpa centang/Aksi/New Record, rapat, satu tombol Filter -> pop-up (Pilihan + Per kolom),
   default 100 baris. Paginasi & saring di server untuk data besar.
5. Relasi lintas database: query terpisah, cocokkan di PHP.
Teks UI lewat Translator::t(). Setelah ubah class Tailwind: npm run build.
Verifikasi ke database dummy (ddt*), lalu commit + push per potongan kerja.

Form dokumen (master-detail)

Dikunci 26 Sep

Form satu dokumen dengan bagian kepala (header) dan daftar item di bawahnya: Quotation, Customer Order, PR, PO, dan seterusnya. Arahan 26 September: New dan Edit adalah form yang sama, dan tombolnya baku mengikuti status dokumen. Berlaku untuk semua modul (pola ala ScriptCase supaya user cepat terbiasa); modul yang menyimpang hanya bila diputuskan per layar.

Terkunci (baca saja)
  • DeleteHanya sebelum confirmed. Dokumen dihapus permanen beserta itemnya.
  • CancelHanya sesudah confirmed. Membatalkan dokumen: status Cancelled + alasan wajib diisi (stat_cancel + cancel_reason), bukan menutup layar.
  • PrintHanya sesudah confirmed. Sebelum itu tombolnya tidak tampil.
  • + New RecordSemua dokumen (Quotation, Customer Order, Delivery Order, dst.) langsung membuka form; pilihan customer/sumber ada di dalam form.
  • Preview cetak = panel dari kiri Dikunci 26 SepTombol Preview Cetak membuka halaman cetak sebagai panel yang meluncur dari kiri di atas form (bukan tab baru, menu tetap utuh). Tutup dengan tombol Tutup, Esc, atau klik area gelap, dan panel langsung hilang. Cetak/PDF dan pilihan kop PPN tetap di bar cetak dalam panel. Contoh: Quotation.

Berikutnya: dibuat sekali sebagai objek DevLib yang dipakai semua form dokumen, Quotation menjadi layar pertama.
