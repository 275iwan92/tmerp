📌 Mockup acuan (docs/mockup/powergrid_demo.html) — replika visual+interaksi Livewire PowerGrid v6 (tema Tailwind default paket, BUKAN tema navy/pastel tmerp). Semua interaksi di sini simulasi JS murni (sort/filter/search/pagination/edit-inline/bulk-select) di atas data contoh statis — bukan koneksi Livewire/DB sungguhan. Tujuannya cuma memperlihatkan RASA & fitur bawaan paket sebelum diputuskan diadopsi atau tidak.

Fitur yang terlihat di sini (bawaan paket, tanpa kode custom kita): sort per kolom (klik header), filter row toggle (dropdown + angka minimum), search global, checkbox select + bulk action bar mengambang, kolom Status = toggle switch langsung klik di tabel (editable column, auto-save di versi asli), kolom Segment = dropdown langsung di tabel (editable select column), expand-row (klik ▸) utk detail tanpa pindah halaman, export dropdown (CSV/XLSX/PDF), pagination dgn per-page selector. Semua itu konfigurasi deklaratif di 1 class PHP (PowerGridComponent), bukan ditulis manual sel-per-sel seperti HasCustomizableGrid/HasSpreadsheetGrid kita.
