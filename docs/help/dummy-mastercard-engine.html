Engine Data Dummy Master Card

PDF Master Card baru → set dummy berlevel (Inquiry, ProDev, ProCost, CO). Dibuat 14 Okt 2026, hanya situs dummy ddt*. Versi teks: docs/help/dummy-mastercard-engine.md. Aturan: docs/PATOKAN-DATA-DUMMY.md.

1. Menjalankan

  • Layar: Developer › Database › Master Card Dummy (PDF) (/v2/dummy/mastercard, developer saja): info input / output (jumlah set per level) dan tombol Run tanpa isian (PDF siap dibagi bergiliran ke Inquiry, ProDev, ProCost, CO; qty 5000, due 21). Perintah di bawah = cara dari terminal dengan kuota sendiri.
  • Perintah: php artisan dummy:mastercard --env=mockup --levels=inquiry:2,prodev:2,procost:2,co:2 --qty=5000 --due=21. Tanpa --levels: semua produk baru ke level Inquiry.

2. Alur proses

PDF di docs/attachments/mastercard/ + gambar extracted/<slug nama pdf>.png|jpg
↓
1. Baca PDF — MasterCardPdfReader::read(): pdftotext -layout, nilai milik label terdekat di atasnya
↓
2. Cek produk — skipReason()
sudah ada (no. desain / kode item / produk aktif) → dilewati
artwork, P x L x T, ukuran pisau, atau bahan kurang → dilewati + alasan
↓
3. Ambil level dari kuota (urut berkas)
kuota habis → dilewati
↓
Level 1 Inquiry — inquiry(): kartu Collection → makeInquiry → flat = pisau per potong → urut bagian → Sales Confirm
↓
Level 2 ProDev — toProdev(): openInProdev → saveLayout(confirm) dari kartu → SpecEngine: BOP, BOM, tinta
↓
Level 3 ProCost — toProcost(): priceAndPublish (CostingEngine, harga contoh)
↓
Level 4 CO — toCo(): Quotation → WIN (Master Product) → CO: pilih qty, due date, Confirm, approval → baris CPDEL

Set level N menjalankan level 1 sampai N lalu berhenti. Berhenti di CO Confirmed: Post to Production, WO, dan plan tidak dijalankan engine.
